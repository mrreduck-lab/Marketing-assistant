# Mail Reader Service

## Назначение

Сервис чтения корпоративной почты RASCHINI для дальнейшего AI-анализа.

## Ограничения первого этапа

Только read-only.

Разрешено:
- подключение к IMAP;
- получение списка писем;
- получение заголовков;
- чтение выбранного письма.

Запрещено:
- отправка писем;
- удаление;
- перемещение;
- изменение статуса прочтения;
- хранение полного архива.

## Технологии

План:

- Python;
- IMAP SSL;
- Docker;
- переменные окружения для секретов.

## Переменные окружения

```
MAIL_HOST=imap.mail.ru
MAIL_PORT=993
MAIL_USER=
MAIL_PASSWORD=
```
