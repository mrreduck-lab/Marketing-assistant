# Marketing Assistant

AI-ассистент маркетинга RASCHINI.

## Mail Assistant

Модуль для анализа корпоративной почты RASCHINI.

Цель:
- находить важные входящие письма;
- определять, кому нужен ответ;
- выделять PR, партнёрства и коммерческие возможности;
- формировать ежедневный briefing для директора по маркетингу.

## Архитектура

```
Mail.ru Business
        |
        | IMAP SSL (read-only)
        |
        v
Mail Reader Service
        |
        v
AI Analysis
        |
        v
Marketing Briefing
```

## Безопасность

- только read-only доступ;
- используется пароль приложения Mail.ru;
- основной пароль не используется;
- письма не хранятся постоянно;
- вложения не скачиваются;
- отправка писем отключена на первом этапе.
