# Mail Assistant

## Назначение

Mail Assistant — модуль проекта Marketing Assistant для анализа корпоративной почты RASCHINI.

Цель: помочь директору по маркетингу контролировать входящие коммуникации, выделять важные письма и не пропускать возможности.

## Архитектура

```
Mail.ru Business
        |
        | IMAP SSL (read-only)
        |
        v
Mail Reader Service
(сервер RASCHINI)
        |
        v
AI Analysis
        |
        v
Marketing Briefing
```

## Принципы безопасности

- Используется только read-only доступ.
- Используется пароль приложения Mail.ru/VK WorkSpace.
- Основной пароль почты не используется.
- Постоянная копия почтового ящика не создаётся.
- Вложения не скачиваются на первом этапе.
- Отправка писем отключена.

## MVP функции

- подключение к IMAP Mail.ru;
- получение списка новых писем;
- чтение заголовков;
- анализ важности;
- классификация коммуникаций.

Категории:

- PR;
- партнёры;
- амбассадоры и инфлюенсеры;
- подрядчики;
- поставщики;
- продажи;
- документы;
- информационные письма.

## Формат результата

```
RASCHINI MAIL AI DAILY

Ответить сегодня:
- отправитель
- тема
- суть
- рекомендуемое действие

Требует внимания:
- возможности
- риски

Без действий:
- информационные письма
```
